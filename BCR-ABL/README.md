## 1. Project Overview

This research project focuses on the molecular detection and quantitative assessment of BCR-ABL1 fusion transcripts in patients with Chronic Myeloid Leukemia (CML), using clinical and molecular diagnostic data from Bangladesh.

The project explores BCR-ABL1 transcript detection patterns, quantitative molecular measurements, and available follow-up results to investigate their relevance to molecular disease monitoring.

The research combines molecular diagnostic assay documentation, clinical data organization, quantitative data analysis, literature review, and clinical interpretation.

## 2. Research Objectives

- Examine BCR-ABL1 fusion transcript detection patterns.
- Review Major, Minor, and Micro transcript screening results.
- Organize and analyze available BCR-ABL1 and ABL1 quantitative measurements.
- Explore normalized ratios and International Scale (IS) values.
- Examine available follow-up molecular measurements.
- Interpret findings in the context of CML molecular monitoring literature.

## 4. Molecular Diagnostic Methods and Assay Documentation

The project involves reviewing molecular diagnostic documentation relevant to BCR-ABL1 detection and monitoring.

### TRUPCR® BCR-ABL1 Kit

The kit documentation covers:
- Major, Minor, and Micro BCR-ABL1 transcript detection
- Reverse transcription and real-time quantitative PCR
- BCR-ABL1 and ABL1 quantitative measurements
- Normalized copy number calculations
- International Scale conversion
- Molecular response assessment

### geneMAP™ BCR-ABL1 p210 (Mbcr) IS-MMR Detection Kit

The documentation covers:
- BCR-ABL1 p210 transcript detection
- ABL1 endogenous control
- Quantitative analysis
- Normalized copy number and IS calculations
- Molecular response assessment

*The specific assay used for each dataset entry will be documented only after verification against the corresponding laboratory records.*
